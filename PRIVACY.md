# Política de Privacidade — KlipShare

**Última atualização:** agosto de 2026

---

## Resumo

KlipShare não coleta, armazena nem transmite dados pessoais para servidores próprios. Toda a operação ocorre localmente no dispositivo do usuário.

---

## 1. Dados acessados pelo aplicativo

KlipShare acessa, exclusivamente no dispositivo do usuário:

- **Destaques de leitura** (`My Clippings.txt`): lidos localmente para exibição no menu e composição do post
- **Highlights do KOReader**: lidos localmente dos arquivos de metadados do dispositivo
- **Token de acesso ao Threads**: gerado pelo próprio usuário e armazenado localmente no arquivo `credentials.conf`, dentro do Kindle

Nenhum desses dados é enviado a servidores de terceiros, exceto o texto do post enviado diretamente à API oficial do Threads (Meta) no momento da publicação.

---

## 2. Dados enviados à API do Threads (Meta)

Ao publicar um destaque, o aplicativo envia à API do Threads:

- O texto do post (trecho do livro, título e hashtags)
- O token de acesso do usuário (para autenticação)

Esses dados são tratados de acordo com a [Política de Privacidade da Meta](https://privacycenter.instagram.com/policy).

---

## 3. Dados que o aplicativo NÃO coleta

- Informações de identificação pessoal
- Dados de localização
- Histórico de navegação
- Dados de uso ou telemetria
- Cookies ou identificadores de rastreamento

---

## 4. Armazenamento do token de acesso

O token de acesso ao Threads é armazenado exclusivamente no arquivo `credentials.conf` dentro do Kindle do usuário. O aplicativo realiza a renovação automática do token diretamente com a API da Meta, sem intermediários.

O usuário é responsável por manter esse arquivo seguro e por revogar o acesso ao aplicativo quando desejar, através das configurações de privacidade do Threads.

---

## 5. Fila offline

Quando o Kindle está sem conexão WiFi, o texto do post é salvo temporariamente em um arquivo local (`cache/queue/`) no próprio dispositivo. Esse arquivo é enviado à API do Threads e excluído automaticamente assim que a conexão é restabelecida.

---

## 6. Compartilhamento de dados

KlipShare **não compartilha nenhum dado** com anunciantes, parceiros ou quaisquer terceiros além da API oficial do Threads (Meta), utilizada exclusivamente para publicar o post autorizado pelo usuário.

---

# Privacy Policy — KlipShare

**Last updated:** August 2026

---

## Summary

KlipShare does not collect, store, or transmit personal data to its own servers. All operations occur locally on the user's device.

---

## 1. Data accessed by the app

KlipShare accesses, exclusively on the user's device:

- **Reading highlights** (`My Clippings.txt`): read locally for display in the menu and post composition
- **KOReader highlights**: read locally from device metadata files
- **Threads access token**: generated by the user and stored locally in the `credentials.conf` file on the Kindle

None of this data is sent to third-party servers, except for the post text sent directly to the official Threads API (Meta) at the time of publishing.

---

## 2. Data sent to the Threads API (Meta)

When publishing a highlight, the app sends to the Threads API:

- The post text (book excerpt, title, and hashtags)
- The user's access token (for authentication)

This data is handled in accordance with [Meta's Privacy Policy](https://privacycenter.instagram.com/policy).

---

## 3. Data the app does NOT collect

- Personally identifiable information
- Location data
- Browsing history
- Usage data or telemetry
- Cookies or tracking identifiers

---

## 4. Access token storage

The Threads access token is stored exclusively in the `credentials.conf` file on the user's Kindle. The app performs automatic token renewal directly with Meta's API, with no intermediaries.

The user is responsible for keeping this file secure and for revoking app access at any time through Threads' privacy settings.

---

## 5. Offline queue

When the Kindle has no WiFi connection, the post text is temporarily saved in a local file (`cache/queue/`) on the device itself. This file is sent to the Threads API and automatically deleted once the connection is restored.

---

## 6. Data sharing

KlipShare **does not share any data** with advertisers, partners, or any third parties other than the official Threads API (Meta), used exclusively to publish posts authorized by the user.
